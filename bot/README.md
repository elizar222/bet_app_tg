# Промо-боты: выдача промокодов по заявкам в каналы

Система из нескольких рабочих ботов + отдельный админ-бот. Все настройки
(промокоды, реф-ссылки, тексты, каналы) вносятся **один раз** в админке и
сразу применяются ко всем ботам — общая база SQLite.

## Как это работает

1. Человек подаёт заявку на вступление в канал.
2. Заявку получают **все** боты, которые админы в этом канале.
3. Отвечает ровно один — тот, за кем закреплён пользователь. Новый человек
   закрепляется за ботом с наименьшей нагрузкой, дальше всегда общается только
   с ним. Так нагрузка размазывается по 10 ботам, и человек не получает
   сообщения от незнакомых ботов.
4. Бот присылает промокод + реф-ссылку, следом — кнопки на остальные каналы
   («подай заявку → получи ещё промокод»).
5. Заявки в основном канале копятся и одобряются пачкой раз в неделю.
   В остальных каналах заявки не одобряются — промокод человек уже получил.

## Установка

```powershell
python -m pip install -r requirements.txt
copy .env.example .env
```

Заполни `.env`:

| Переменная | Что это |
|---|---|
| `BOT_TOKENS` | токены рабочих ботов через запятую |
| `ADMIN_BOT_TOKEN` | токен админ-бота (в каналы не добавляется) |
| `ADMIN_IDS` | твой Telegram ID (узнать: `@userinfobot`) |
| `TIMEZONE` | часовой пояс расписаний, по умолчанию `Europe/Moscow` |

## Подготовка каналов — обязательные шаги

Без этого бот физически не сможет написать человеку:

1. В канале включены **«Заявки на вступление»** (Invite Links → Request Admin
   Approval). Ссылка для рекламы должна быть именно такой — с заявкой.
2. **Каждый** рабочий бот добавлен в канал администратором с правом
   **«Добавлять подписчиков»** (Add Members / Invite Users via Link).
3. Канал добавлен в админке: `📢 Каналы → ➕ Добавить канал`. ID можно не
   искать — просто перешли админ-боту любой пост из канала.
4. Каналу назначен промокод, иначе выдавать нечего.

## Запуск

```powershell
python run.py
```

Останов — `Ctrl+C`. Логи: консоль и `data/bot.log`, база: `data/bot.db`.

## Мини-апп (Hedge Terminal)

Сервер мини-аппа запускается вместе с ботами той же командой `python run.py`
и работает с той же базой: промокоды и каналы из админки сразу видны в
разделе «Бонусы».

Экраны: **Главная** (банк, ставки в игре, Live, value дня, падения кэфов,
экспресс дня, статистика канала), **Матчи** (фильтры, лиги), **Матч**
(вероятности, перевес, ожидаемый счёт, кэфы за 24 ч, форма, xG, личные
встречи, таблица, средние, судья, травмы, Live-давление), **Хедж**
(калькулятор с тремя режимами и сравнением с выкупом), **Статистика**
(трекер ставок, ROI, серии, разрезы), **Бонусы** (промокоды, каналы, VIP).

Пока не подключены платные API, матчи — **демо-данные** (в приложении
стоит пометка). Трекер ставок, хедж, промокоды и VIP — настоящие.

### Проверить в браузере без Telegram

В `.env` поставь `WEB_DEV_USER_ID=<твой Telegram ID>`, запусти `python run.py`
и открой http://127.0.0.1:8080. Перед боевым запуском верни `0`.

### Открыть в Telegram со своего ПК

Telegram открывает мини-аппы только по `https`. Бесплатный туннель:

1. Скачай `cloudflared` для Windows:
   https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
2. Во втором окне PowerShell:
   ```powershell
   cloudflared tunnel --url http://127.0.0.1:8080
   ```
   Он напечатает адрес вида `https://something.trycloudflare.com`.
3. Впиши его в `.env` → `WEBAPP_URL=https://something.trycloudflare.com`
   и перезапусти `python run.py`.

У рабочих ботов появится кнопка «📊 Открыть терминал» в меню и под /start.
Пока ПК выключен или туннель закрыт, мини-апп не открывается. Адрес
бесплатного туннеля меняется при каждом запуске — обновляй `WEBAPP_URL`.

### VIP

Бесплатно — 1 расчёт хеджа в неделю в режиме «Поровну» (число меняется в
`⚙️ Тексты и ссылки`). Пользователь вводит свой 1win ID в мини-аппе, ты
проверяешь депозит в кабинете партнёрки и выдаёшь VIP в админке: `👑 VIP`.
Статистика мини-аппа — `📱 Мини-апп`.

## Админка

Напиши `/start` админ-боту.

- **🎟 Промокоды** — код, описание, своя реф-ссылка (пусто = глобальная), вкл/выкл.
- **📢 Каналы** — ID, ссылка-приглашение, режим заявок (раз в неделю / не
  одобрять / сразу), день и час одобрения, какой промокод выдавать, показывать
  ли канал в офферах. Есть кнопка «Одобрить сейчас».
- **⚙️ Тексты и ссылки** — глобальная реф-ссылка и все шаблоны сообщений.
  Плейсхолдеры: `{name}`, `{promo}`, `{promo_title}`, `{ref_link}`, `{channel}`.
- **📨 Рассылка** — разовая с кнопкой и настройки еженедельной (день, час, текст).
- **🤖 Боты** — нагрузка по каждому боту и сколько людей его заблокировали.
  Выключённый бот перестаёт получать новых юзеров, но продолжает вести своих.
- **📊 Статистика** — юзеры, заявки, выданные промокоды, разрез по каналам.

## Перенос на сервер

Код не завязан на Windows. На сервере:

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python run.py
```

Дальше — `systemd`-юнит с `Restart=always`. Базу можно оставить SQLite или
переключить на Postgres, поменяв только `DATABASE_URL` (нужен `asyncpg`).
Файл `data/bot.db` при переезде забирай с собой — в нём закрепления
пользователей за ботами.
